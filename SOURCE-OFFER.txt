Orbit for Phorepoc -- licence notice and source offer

The "Orbit" package contains the Hb UI framework (Orbit), its theme server and device dialogs, the Qt homescreen and its
plug-ins, the Qt service framework / publish-and-subscribe / system info libraries, the Qt extensions, the content arsenal and
activity framework, built for the PC image (x32). It needs the "Qt" package (Qt 4.8.7) and nothing else needs it.

Orbit (Hb) was the UI of Symbian^4, the next release the Symbian Foundation planned. It was published as open source in 2010
and never shipped on a phone. The sources are the Symbian Foundation's, copyright Nokia Corporation and/or its subsidiaries:
  - Hb (hbcore, hbwidgets, hbinput, hbfeedback, hbutils, the theme server, the device dialog server): GNU Lesser General
    Public License 2.1 with the Nokia Qt LGPL Exception 1.1 (LICENSES/LGPL-2.1.txt, LICENSES/Nokia-Qt-LGPL-exception-1.1.txt);
  - the homescreen, the content arsenal, the activity framework, Qt Mobility parts, the Qt extensions, the software component
    registry and the rest: the Eclipse Public License 1.0 (LICENSES/EPL-1.0.txt) -- each file's header names its licence.
The licence texts are installed with the package (\resource\phe\orbit\licences\).

The Hb libraries are dynamic libraries: you can replace them with your own build of Hb (same ABI) and the applications that use
them keep working.
